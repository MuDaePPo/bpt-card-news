DP World, 에콰도르 포사르하(Posorja)항 안벽 확장 가동식

일시 확장구간 가동식 2026년4월23일 · 주체 DP World · 위치 에콰도르 과야스주 포사르하(Posorja)항
  • DP World가 에콰도르 포사르하항의 안벽 확장 프로젝트 가동식을 2026년4월23일 개최했다고 발표함
  • 이번 확장으로 처리능력이 기존보다 40% 늘어난 연 140만TEU로 확대됨
  • 안벽 길이는 기존 467.5m에서 2026년4월 기준 700m까지 늘어났으며, 일부 자료는 연말까지 800m 목표를 제시함(최종 길이는 추가 확인 필요)
  • 전동식 슈퍼포스트파나막스(Super Post-Panamax) 안벽크레인 2기가 추가 도입됨
  • 해당 공사는 1억9000만달러 이상 규모의 민간투자 프로그램의 일환으로 추진됨(안벽 공사 자체는 별도로 1억4000만달러 규모라는 보도도 있어 범위로 제시함)
